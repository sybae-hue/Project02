📋 Google Apps Script 웹 앱 배포 안내

이 웹 앱은 CSS와 JS가 모두 하나의 Index.html 파일 안에 포함되어 있어 Google Apps Script의 HtmlService에서 별도 빌드 없이 바로 구동됩니다.

  1. Google 드라이브에서 새로 만들기 > 더보기 > Google Apps Script (또는 스프레드시트 확장 프로그램)를 엽니다.
  2. Code.gs에 아래 함수를 작성합니다:
    function doGet() { return HtmlService.createHtmlOutputFromFile('Index') .setTitle('점심 메뉴 룰렛') .addMetaTag('viewport', 'width=device-width, initial-scale=1.0'); }
  3. 왼쪽 메뉴에서 + 버튼 > HTML을 누르고 파일명을 Index로 지정합니다.
  4. 아래 [전체 HTML 복사] 버튼을 누른 후 Index.html에 붙여넣고 배포 > 새 배포를 완료하면 나만의 점심 룰렛 웹 앱이 완성됩니다!
